A300-600 Flow Trainer

An interactive procedure trainer for the A300-600 cockpit. It's built in two layers: a core flow engine that stores each procedure as an ordered sequence and validates every action, and a clickable cockpit UI where the pilot taps switches in the correct order and gets instant yes/no feedback — plus a memory-item drill for red-alert recall.

01 · Core component

The flow-validation engine

Each procedure is data: an ordered list of cockpit actions. The engine presents the next expected action, checks every click against the sequence, and scores the run — the same core drives both the cockpit trainer and the memory-item drills.

1

Define flow

Each procedure stored as an ordered sequence of cockpit actions with their panel location.

2

Present

Render the cockpit and highlight the next expected action; the pilot taps the switch.

3

Validate

Compare the click against the expected step — instant yes/no, wrong taps don't advance.

4

Score

Track completion, errors and time; feed weak steps back into drill mode.

Core model
  • Procedures as ordered action sequences
  • Each action: panel · control · expected state
  • Memory items flagged as red-alert
What the UI gets
  • The next expected action to highlight
  • Instant correct / incorrect verdict
  • Progress, error count and recall score
