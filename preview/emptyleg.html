Empty-Leg Charter Portal

A full-stack platform for private-jet empty legs: it ingests available legs from the ops system, prices them automatically, publishes public booking pages with a live map, and gives the operator a complete admin area for flights, requests, users and pricing. Live in production.

01 · Core function

The leg-to-booking engine

A pipeline turns raw empty legs from the operator's system into priced, bookable public listings — and routes every inquiry back into a managed admin workflow.

1

Ingest

Pull available empty legs (route, aircraft, date, seats) live from the ops system and normalize them.

2

Price

Apply pricing rules — base rate, markup and last-minute discount — per aircraft type and route.

3

Publish

Render public booking pages and a live map; visitors browse legs and send an inquiry.

4

Manage

Admin area handles requests, flights, users and pricing, with status tracking from inquiry to confirmed.

Inputs
  • Live empty legs from ops system
  • Aircraft & route master data
  • Pricing & markup rules
Outputs
  • Public booking pages + live map
  • Priced, filterable flight listings
  • Managed inquiry → booking workflow
